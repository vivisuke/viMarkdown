## はじめに

マークダウンエディタ viMarkdown を開発中だ。Qt C++ によるネイティブデスクトップアプリである。

ver 0.3 は、5月に開発版、8月にアルファ版、10月にベータ版と進み、12月に RC・Stable を予定している。その目玉のひとつが vi/ex コマンドサポートだ。

ただし、viMarkdown は Vim の全コマンドをサポートするものではない。対応しているのは、ノーマル・ビジュアル・挿入の3モードと無限 undo 程度である。ex コマンドについても、対応は一部にとどまっている。

それでも、vi コマンドの挙動が1文字でもずれていると Vim おじさんが怒るのだ。

## なぜVimおじさんは1文字のずれで怒るのか

Vim おじさんは、カーソル移動時にどのコマンドを使うか意識していない。移動先を認識するだけで、手が勝手に vi コマンドを奏でる。

そのため、カーソル移動が1文字でもずれるのには耐えられないのである。

## 自動テストの必要性

vi コマンドは組み合わせが爆発的だ。operator × motion × count の掛け算になる。

- operator: `c` `d` `y` `<` `>`
- motion: `h` `j` `k` `l` `Spc` `BS` `w` `W` `e` `E` `b` `B` `0` `^` `$` `f` `F` `t` `T` `,` `;`

カーソル位置が1文字でもずれると即アウトだ。手動テストは無理ゲーである。局所的な対処による副作用も心配だ。

## テストランナー

テストランナーは viMarkdown 本体に組み込んだ。専用のテストツールを別に作るのではなく、アプリ自身にテストケースを一括実行する仕組みを持たせた。

使い方は単純で、メニューからテストを実行すると、登録されたテストケースをすべて流し、結果を表示する。

## テストケース

テストケースは、次の形式のデータとして定義する。

- テスト名
- 初期テキスト・カーソル位置
- （vi/ex コマンド, 期待されるテキスト・カーソル位置）の繰り返し

カーソル位置は `┃`、選択範囲は `《` `》` で表現する。

```cpp
{ "Move cursor left", "h┃ello\n",
    {"h", "┃hello\n", "h", "┃hello\n", } },
{ "Visual mode", "h┃ello\n",
    {"v", "h《┃e》llo\n", "l", "h《e┃l》lo\n", } },
{ "Ex Delete - Current Line (:d)", "line 1\nli┃ne 2\nline 3\n",
    { ":d", "line 1\n┃line 3\n" } },
```

コマンドを1つ実行するたびに、その時点のテキストとカーソル位置が期待どおりかを検証する。1ケースの中でコマンドを連続して実行し、途中の状態まで含めてチェックできるのがポイントだ。

## テスト結果メッセージ

正常時は、何をテストしたかとテスト件数を表示する。

テスト失敗時は、Before:（実行前）➔ Commands: ➔ Expected: ➔ Actual: を表示する。実行前の状態、実行したコマンド、期待した結果、実際の結果を並べるので、どこで・どうずれたかが一目で分かる。

## テストケース作成

テストケースは、基本的に生成 AI に作成してもらう。Muse 先生・Gemini 先生が作成したテストケースを、チャッピー先生（ChatGPT）・Claude 先生がレビュー・修正・追加する体制だ。

テスト失敗時も AI に評価させる。失敗の原因は、vi/ex 実装、テストケース、自動テストランナーのいずれにもありうるからだ。

AI 生成テストケースには（正確には数えていないが）全体の1〜2%程度の誤りがあった。

実装の誤りとテストケースの誤りが一致すると、問題が表面化しない。そこで Muse が VM 上で Vim を操作し、テストケースに誤りがないかをチェックする体制にした。

## 結果

10月末時点の結果は次のとおりだ。

```text
Total: 0 failed / 611 tested. (Success:100.0%)
```

## まとめ

- vi の挙動を忠実に再現するのは想像以上に難しく、コストがかかる
- だが自動テストがあると安心して実装できる
- テストケース作成は手間がかかるが、生成 AI に任せられる（ただし実際の Vim でのクロスチェックは必要）
- 結果：Vim おじさんにも怒られにくくなる

viMarkdown のダウンロード・試用よろしく〜。
