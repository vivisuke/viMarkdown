# viMarkdown 
# 10万行でもサクサク編集できるようにしたい

## 目次
- 2ペイン方式マークダウンエディタ viMarkdown 開発中
  - https://github.com/vivisuke/viMarkdown
- 現在の課題：巨大マークダウンでもサクサク編集したい
  - 巨大：10万行（50行/page * 2000ページ）
  - 0.1秒未満の処理時間（10打鍵/秒）
- 現在（ver 0.3）は１文字挿入・削除でも全変換を行っている
  - O(N)、２千行程度が我慢できる限界
  - 100・1,000・10,000・100,000 行MD文書先頭付近で１文字編集時間計測
    - viMardown 0.3 実測結果
- 解決策：局所的な変換処理が必要
  - 局所的変換処理にもいろいろ種類（方法）がある
    - 局所の定義、検知方法
    - 文字単位、MD構文単位、段落単位、見出し＋本文単位、AST単位
  - 今回は、処理の単純さと効果のバランスから「見出し行＋本文」単位での変換を採用
  - より高度な局所変換は v0.5 以降の課題とする
- 実は遅延ロード＋バックグラウンド変換も必要だが、v0.5 以降の課題とする
  - ロード時には全文を変換する必要がある
  - が、画面に表示されるのは数１０行だけなので、必要な部分のみ変換し、
  - 残りはバックグラウンドで読み込み・変換する必要がある
- 「見出し行＋本文」単位局所変換
  - エディタ、プレビューは QPlainTextEdit QTextEdit 派生クラス
  - 共に QTextDocument でテキストを保持し、QTextBlock により行単位に管理されている
  - QTextBlock オブジェクトは userState として 32bit 値を保持できる
  - エディタ・プレビュー共に、見出し行は userState = US\_HEADING と設定しておく
  - 見出し行＋本文単位変換アルゴリズム：
      - エディタ：文書先頭に向かって編集されたブロックの見出し行を探す → block
      - プレビュー：block に対応するブロックを探す → block2
      - プレビュー：block2 から次の見出し行を探す → oldEndBlock
      - プレビュー：block2 ～ oldEndBlock直前までを削除
      - block ～ 次の見出し行ブロック直前までのテキストを block2 位置に insertMarkdown()
  - エッジケース？：
    - 見出し行を挿入した場合
    - 見出し行を非見出し行に変えた場合
- 結果：O(N) → O(B) になった
  - ※ N：文書全体行数、B: 「見出し＋本文」行数、通常は N ≫ B
  - 実測値：100・1,000・10,000・100,000 行MD文書先頭付近で１文字編集
    - テストプロジェクトにより計測
- まとめ・今後の課題
  - 10万行マークダウンでもさくさく編集できるように
  - 「見出し行＋本文」単位局所変換をテスト実装してみた
  - 処理時間が O(N) → O(B) になった（N ≫ B）
  - コードブロックに #行 があると破綻する
  - 遅延ロード・遅延変換処理が必要
