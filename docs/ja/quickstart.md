# viMarkdown 簡単な入門
## 概要
viMarkdownは、viの高速な編集操作と、直感的で効率的な執筆環境を融合したデスクトップ向けMarkdownエディタです。
文章の構造を素早く把握できる「アウトラインバー」、快適な入力環境を提供する「エディタ」、編集結果のリアルタイム確認および直接的なテキスト入力・編集が可能な「プレビュー画面」、検索結果やログを表示する「OutputBar」、そして日々のタスクや日記の管理をサポートする「カレンダーバー」が連携した、統合的な編集環境を提供します。

ver 0.3では、本アプリの中核となる「viコマンド(ノーマル／挿入／ビジュアル／コマンドラインモード)」をネイティブ搭載し、キーボードから手を離さずに効率的な編集操作を行えるようになりました。
さらに、カレンダーと連動した日記の自動生成やToDo進捗の可視化、長文の閲覧性を高める見出し折り畳み(Folding)、SVGデータのリアルタイム描画、2つの文書を並べて比較・編集できるDiffモード、プロジェクト全体を横断検索できるGrep検索機能など、実用的な機能を大幅に拡充しています。

主な対象ユーザーは、技術文書やWeb記事、研究論文、日報やレポートなど、論理的・構造的な文章を執筆するエンジニア、ライター、研究者、理系学生です。
viコマンドによる効率的な編集操作、プレビュー画面上でのシームレスなテキスト編集、MarkdownとSVGによる豊かな表現力、そしてカレンダーによるタスク管理を活用しながら、文章の構成や内容そのものに集中できる執筆環境を提供します。

動作環境は、Qt 6を利用したマルチプラットフォーム(Windows / macOS / Linux)に対応しています。

※ 本ガイド(viMarkdown 簡単な入門)自体も、viMarkdownを使用して作成されました。

### アウトラインバー（左ペイン）
執筆中の文書構造をツリー形式で表示します。
- **見出し抽出:** 文書内の #（H1）や ##（H2）といった見出しを自動的に解析し、階層構造で表示します。
- **ファイル一覧:** 現在開いている複数のファイルをフォルダ形式で管理し、素早く切り替えることができます。
- **クイックジャンプ:** ツリー内の項目をクリックすることで、エディタおよびプレビューを該当箇所へ瞬時に移動させることが可能です。

### エディタ領域（中央ペイン）

マークダウンを記述するメインの作業エリアです。

- **タブインターフェース:** 複数の文書を同時に開き、上部のタブで切り替えながら並行して執筆できます。
- **シンタックスハイライト:** 見出しが赤色で強調されるなど、マークダウン記法がリアルタイムで色付けされ、プレーンテキストよりも構造が把握しやすくなっています。
- **編集操作:** 通常のテキストエディタと同様の直感的な入力・修正が可能です（※viコマンド機能は今後のバージョンで実装予定）。

### プレビュー画面（右ペイン）

エディタで入力したマークダウンが、最終的にどのような外見になるかをリアルタイムに表示します。

- **ビジュアル確認:** 太字、リスト、見出し、テーブルなどがHTMLとしてレンダリングされます。
- **仕上がりチェック:** 執筆しながら、改行の具合や構造のミスを視覚的に確認できます。
- **HTMLソース表示:** ツールバーの [Source] ボタンを選択することで、レンダリングされた HTMLソースコードを表示 することができます。生成されたコードをコピーして、他のWebサイトやブログへ貼り付けて利用するといった用途にも活用可能です。

### メニュー・ツールバー（上部）

主要な機能に素早くアクセスするためのエリアです。

- **標準メニュー:** ファイル操作（保存、開く）、編集（元に戻す、やり直し）、検索などの標準的な機能を備えています。
- **書式ボタン:** 太字(B)、斜体(I)、打ち消し線(S)といった頻繁に使用するマークダウン記法を、選択範囲に対してワンクリックで適用できます。
- **表示切り替え:** 「HTML」表示と「Source（ソースコード）」表示を切り替えるボタンにより、レンダリング結果の詳細を確認することが可能です。

### ステータスバー（下部）

現在の編集状態をリアルタイムで表示します。

- **カーソル位置:** 右端に「行：列」の形式（例：12:7）で現在のカーソル位置を表示します。
- **情報通知:** アプリの状態やメッセージが表示されます。

## vi コマンドによる高速編集

viMarkdown は、キーボードから手を離さずに編集完結できる **vi 操作体系** を備えています。

### モードの切り替え
- **ノーマルモード:** `Esc` キーを押すと遷移します。移動やカット・ペーストなどのコマンドを実行します。
- **挿入モード:** ノーマルモードで `i`（カーソル位置で挿入）、`a`（直後で挿入）、`o`（下に行挿入）、`A`（行末挿入）などを押すと遷移し、テキストを入力できます。
- **ビジュアルモード:** `v`（文字選択）または `V`（行選択）を押すと選択モードに入ります。
- **コマンドラインモード:** `:` を押すと画面下部のステータスバーがコマンドラインになり、ex コマンドを入力できます。

### 代表的な vi コマンド
- **カーソル移動:** `h`（左）、`j`（下）、`k`（上）、`l`（右）、`w`（次単語）、`b`（前単語）、`0`（行頭）、`$`（行末）、`gg`（先頭行）、`G`（末尾行）
- **編集:** `x`（1文字削除）、`dd`（1行カット）、`yy`（1行コピー）、`p`（ペースト）、`u`（元に戻す）、`.`（直前編集の再実行）
- **検索:** `/パターン`（順方向検索）、`?パターン`（逆方向検索）、`n` / `N`（次 / 前のマッチへ）
- **ex コマンド:** `:w`（保存）、`:q`（閉じる）、`:e ファイル名`（ファイルを開く）

## カレンダー・日記機能

日々のタスク管理や作業ログ（日報）の作成を自動化します。

1. **カレンダーの日付をクリック:**  
   カレンダー上の日付（例：8月8日）をクリックすると、`diary/2026/08/20260808.md` が自動作成（または読み込み）されてエディタで開きます。
2. **テンプレート自動適用:**  
   `diary/template.md` が設定されている場合、初回生成時に自動的にテンプレートが流し込まれ、`{{date}}` がその日の日付に自動置換されます。
3. **ToDo 進捗の可視化:**  
   日記内に `- [ ] タスク` を記述すると、達成状況に応じてカレンダーの日付背景色やステータスアイコン（★ / 🔥）が自動更新されます。

## 見出し折り畳み（Folding）

長文ドキュメントの閲覧性を向上させる折り畳み機能を搭載しています。

- **マウス操作:** 行番号横のアイコン（▼ / ▶）をクリックして見出し配下の本文を展開・折り畳みできます。
- **vi コマンド操作:** 
  - `zc`: カーソル位置の見出しを折り畳む
  - `zo`: 折り畳みを展開する
  - `za`: 折り畳み/展開をトグル切り替え
  - `zM`: 文書全体のすべての見出しを折り畳む
  - `zR`: 文書全体のすべての見出しを展開する

## マークダウンで文章を書いてみよう

viMarkdownは、直感的な記法で構造化された文書を素早く作成するためのツールです。  
まずはこのガイドを参考にして、実際にエディタへマークダウンを書いてみましょう。入力した内容がプレビュー画面にリアルタイムに反映される様子を、自分の目で確かめながら進めてみてください。

### リアルタイムプレビュー

中央のエディタ領域でテキストを入力・編集すると、その結果が即座に右側のプレビュー画面に反映されます。保存操作を待つことなく、常に最終的な仕上がりを確認しながら執筆に集中できます。

### 見出し

行頭に `#` 記号を付けることで見出しを作成します。`#` の数によって見出しのレベル（H1〜H6）を指定できます。
*   `# 見出し1`（タイトル）
*   `## 見出し2`（大見出し）
*   `### 見出し3`（中見出し）
*   `#### 見出し4`（小見出し）
※ `OutlineBar` には、ここで指定した見出しが自動的にリストアップされます。

### 本文

特別な記号を付けずにテキストを入力すると、通常の段落（本文）として扱われます。
*   **段落の区切り**: 空行（何も入力されていない行）を一行挟むことで、新しい段落として区切られます。
*   **行内での改行**: 行の末尾に**半角スペースを2個追加**すると、段落を変えずに次の行へ改行（強制改行）することができます。段落を分けたくない、単なる改行を行いたい場合に便利です。

### リスト
箇条書きや番号付きのリストを簡単に作成できます。
*   **箇条書き**: 行頭に `-`（ハイフン）または `*`（アスタリスク）と半角スペースを入力します。
  *   行頭にスペースを入れることで、リストをネスト（階層化）することも可能です。
*   **番号付きリスト**: 行頭に `1.` などの数字とピリオド、半角スペースを入力します。

### 文字強調
特定の単語やフレーズを装飾して目立たせることができます。
*   **太字**: 強調したい文字を `**` で囲みます。 （例：`**重要**` → **重要**）
*   **イタリック（斜体）**: 文字を `*` で囲みます。 （例：`*斜体*` → *斜体*）
*   **打ち消し線**: 文字を `~~` で囲みます。 （例：`~~削除~~` → ~~削除~~）
※ これらの装飾は、ツールバーの [B] [I] [S] ボタンを使って、選択範囲に対して簡単に適用することもできます。

### 罫線ブロック
#### 罫線ブロックの定義
罫線を描きたい範囲を、以下のように keisen 指定のコードブロックで囲みます。

> ```keisen
> 
> （ここに罫線を描画します）
> 
> ```
#### 罫線モードの操作方法
エディタ上で Shift + F5 キーを押すと「罫線モード」がオンになります（もう一度押すとオフになります）。モードがオンの時、以下の操作で自在に描画できます。  
**罫線を引く:** Ctrl + 矢印キー (↑ ↓ ← →)
カーソル移動に合わせて罫線が引かれます。  
角（コーナー）や交差点（十字・T字）は、接続状況に応じて自動的に適切な形状に変換されます。  
**罫線を消す:** Ctrl + Shift + 矢印キー  
引いた罫線を反対になぞることで、消去できます。
### 罫線保護機能
viMarkdownの罫線ブロックは、単なるアスキーアートではありません。枠の中に文字を入力する際、右側の罫線位置を自動的に維持する「罫線保護機能」が働きます。  
- 枠内で文字を入力・削除しても、右側の壁がズレて図形が崩れることはありません。
- 全角文字や半角文字が混在しても、垂直な罫線がガタガタにならないよう自動でパディング調整が行われます。

### CSVブロック

- 「\```CSV」「\```」行で囲まれた部分はCSVデータと解釈され、表として描画される。
- 先頭行はヘッダ行として扱われる。
- 先頭行・本体1行ごと背景色（ゼブラカラー）は設定ダイアログで変更可能。
- すでにCSV形式データがある場合は、そのまま貼り付けて、前後に「\```CSV」「\```」行を挿入するだけで利用できます。

> \```CSV
> h111, h22, h333
> "1", "31,415,926,535", hoge
> abc, 12, xyz
> "1", "31,415,926,535", hoge
> abc, 12, xyz
> \```
　　　↓  
　  
```CSV
h111, h22, h333
"1", "31,415,926,535", hoge
abc, 12, xyz
"1", "31,415,926,535", hoge
abc, 12, xyz
```


## ファイル操作と終了

### ファイル保存

編集した内容を保存するには、メニューまたはショートカットを利用します。
*   **上書き保存**: メニューの `File` -> `Save` を選択するか、`Ctrl + S` を押します。
  *   **新規文書の場合**: 「無題-1」などのまだ名前のない文書で `Ctrl + S`（保存）を実行すると、自動的に**「名前を付けて保存」ダイアログが表示**されます。ここでファイル名を指定して保存してください。
  *   **既存文書の場合**: すでに名前があるファイルは、そのまま上書き保存されます。
*   **名前を付けて保存**: すでに名前があるファイルを、別の名前でコピーして保存したい場合は、`File` -> `Save As` を選択してください。

### 既存のマークダウンファイルを開く

コンピュータ内に保存されている `.md` ファイルを読み込んで編集できます。
*   **ファイルを開く**: `File` -> `Open` を選択し、目的のファイルを選択してください。開かれたファイルは新しいタブとして追加されます。
*   **Recent Files（最近使ったファイル）**: `File` -> `Recent Files` メニューから、過去に編集したファイルを履歴から素早く開くことができます。何度も編集するファイルを探す手間が省けます。

### 文書クローズ
編集が終わったタブを閉じることができます。
*   **閉じ方**: メニューの `File` -> `Close` を選択するか、ショートカットキー **`Ctrl + W`** を押すと、現在のタブが閉じられます。
*   **保存の確認**: 未保存の内容がある場合は、タブを閉じる前に「変更を保存しますか？」という確認ダイアログが表示されます。不注意で作業内容を失うのを防ぎます。

### アプリ終了
viMarkdownを終了します。
*   **終了方法**: ウィンドウ右上の `×` ボタンをクリックするか、メニューの `File` -> `Exit` を選択します。
*   **一括確認**: 複数のタブで未保存の文書がある場合、終了前にそれらを保存するかどうかを順に確認します。
