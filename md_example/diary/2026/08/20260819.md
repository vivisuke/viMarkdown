## Notes
追加すべきテストケース：
### 1. 【最優先】ヤンク系コマンド（`y`, `yy`, `y<move>`）
現状のテストは `dd` や `dw` でカットした後のペーストが中心のため、「テキストを消さずにコピーする」ヤンク単体のテストを拡充すべきです。

* **`yy` / `<num>yy`**: カレント行のコピー（行は削除されずそのまま残る確認 ＋ `p` でペースト）
* **`yw` / `y$` / `y0` / `y^` / `ye` / `yb`**: 単語や行末までのヤンク
* **`yj` / `yk`**: カレント行＋上下行の行単位ヤンク（※ 先日修正した `0918` の検証）
* **ヤンク後のカーソル位置の検証**: Vim では `yw` や `y$` を行っても **カーソル位置は移動しない**（元の位置に留まる）ことの確認

---

### 2. 【最優先】変更オペレータ（`c`, `cc`, `c<move>`）
削除して挿入モードに入る「変更（Change）」系は、テキストの削除と文字列挿入が組み合わさるため、バグが潜みやすい重要領域です。

* **`cw` / `ce`**: 単語の変更（Vim の特例仕様: `cw` は単語末尾の空白を削除せず、単語部分のみを置き換える動作）
* **`cc` / `S`**: カレント行全体をクリアしてインデント位置から挿入モードへ
* **`c$` / `C`**: カーソル位置から行末までの変更
* **`c0` / `c^`**: 行頭までの変更
* **`cb` / `ch` / `cl`**: 前方向・1文字の変更
* **`<num>cw` / `<num>cc`**: カウント指定の変更

---

### 3. 行結合・インデント・文字反転（`J`, `>>`, `<<`, `~`）
エディタの便利機能として頻繁に使われる単発コマンド群です。

* **`J`（行結合）**:
  * 次行と空白1つで結合されること
  * 次行が空行の場合の結合挙動
  * カウント指定（`3J` で 3 行まとめて結合）
  * `J` 実行後の `u`（1回で元に戻るか）
* **`>>` / `<<`（インデント操作）**:
  * カレント行のシフト
  * カウント指定（`3>>`, `2<<`）
  * ドットリピート（`>>.` で連続インデント）
* **`~`（大文字・小文字反転）**:
  * 1文字反転、カウント指定（`5~`）
  * 行末文字での反転とカーソル移動（行末では進まず留まる）

---

### 4. ジャンプ・大規模移動系（`G`, `gg`, `H`, `M`, `L`, `]]`, `[[`）
長文編集に必須となるカーソルジャンプのテストです。

* **`gg` / `G`**: 文書先頭行（1行目）への移動 / 文書末尾行への移動
* **`<num>gg` / `<num>G`**: 指定行番号へのジャンプ（例: `10G` で 10 行目の先頭非空白文字へ）
* **`]]` / `[[`**: Markdown 見出し（`#`, `##`）単位の前後のセクション移動
* **オペレータ連携**: `dG`（カレント行から末尾まで削除）、`dgg`（カレント行から先頭まで削除）

---

### 5. ビジュアルモード（`v`, `V`）＋ 各種オペレータ
選択範囲に対する操作のテストです。

* **文字ビジュアル（`v`）**:
  * `v<move>d` / `v<move>x`（選択範囲の削除）
  * `v<move>y`（選択範囲のヤンク ＋ 選択解除 ＋ ペースト）
  * `v<move>c`（選択範囲の置換挿入）
  * `v<move>~` / `v<move>u` / `v<move>U`（選択範囲の大文字小文字変換）
* **行ビジュアル（`V`）**:
  * `Vjd`（2行削除）、`Vkd`
  * `Vjy` 後の `p`（行単位ペースト）

---

### 6. 検索系コマンド（`*`, `/`, `?`, `n`, `N`）
* **`*`**: カーソル下の単語を前方検索して次のマッチへジャンプ
* **`/pattern\n` / `?pattern\n`**: 前方/後方検索
* **`n` / `N`**: 検索方向への再検索 / 逆方向への再検索
* **検索モーション連携**: `d/foo\n`（マッチ位置まで削除）

---

### 7. ex コマンド（`:` コマンドライン）
* **`:<range>d`**: `:2,4d`（2〜4行目削除）、`:1d`、`:d`
* **`:<range>s/old/new/g`**: 単一行・全行（`:%s`）での正規表現置換
* **`:g/pattern/d`**: 条件マッチ行の一括削除
