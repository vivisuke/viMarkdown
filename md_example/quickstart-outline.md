## 1. はじめの一歩
### 新規文書
- ファイル > 新規タブ Ctrl + T：新規文書タブ作成
- タブリスト左の「＋」押下でも新規文書タブ作成
### ファイルを開く
- ファイル > 開く Ctrl + O：ファイルオープンダイアログ→指定ファイルを開く
### カーソル移動
- マウスクリック
- ↑↓←→ カーソルキー：上下左右カーソル移動
- Home, End：行頭・行末移動
- Ctrl + Home, Ctrl + End：文書先頭・末尾移動
## 2. Markdownを心地よく書く
### リスト補完
```
- テキスト [カーソル]
```
- 上記状態で改行押下 → リスト補完
```
- テキスト
- [カーソル]
```
- 改行直後のテキストが無い状態で改行押下 → 補完テキスト削除

※ 番号付きリスト（1.）やタスクリスト（- [ ]）でも同様に補完されます。
### インデント・アンインデント
- Tab押下：インデント
- Shift + Tab：アンインデント
- ※インデントは半角空白２個
### Undo/Redo
- 編集 > もとに戻す Ctrl + Z：編集操作を取り消す
- 編集 > 繰り返し Ctrl + Y：元に戻した編集操作を再実行
### プレビュー内編集
- プレビュー内でも文字挿入・削除などの単純な編集が可能
## 3. ファイルの保存と終了
- ファイル > 保存 Ctrl + S：現文書を保存
- ファイル > 名前を付けて保存 Ctrl + Shift + S：現文書を別名保存
- ファイル > 閉じる Ctrl + W：現文書を閉じる
- ファイル > 終了：viMarkdown を終了
