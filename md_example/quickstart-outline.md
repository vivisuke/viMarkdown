# 【第1部：5分で学ぶ viMarkdown の基本】
## 1. はじめの一歩
### 新規文書
- ファイル > 新規タブ Ctrl + T：新規文書タブ作成
- タブリスト左の「＋」押下でも新規文書タブ作成
### ファイルを開く
- ファイル > 開く Ctrl + O：ファイルオープンダイアログ→指定ファイルを開く
### カーソル移動
- マウスクリック
- ↑↓←→ カーソルキー：上下左右カーソル移動
- Home, End：行頭・行末移動
- Ctrl + Home, Ctrl + End：文書先頭・末尾移動
## 2. Markdownを心地よく書く
### リスト補完
```
- テキスト [カーソル]
```
- 上記状態で改行押下 → リスト補完
```
- テキスト
- [カーソル]
```
- 改行直後のテキストが無い状態で改行押下 → 補完テキスト削除

※ 番号付きリスト（1.）やタスクリスト（- [ ]）でも同様に補完されます。
### インデント・アンインデント
- Tab押下：インデント
- Shift + Tab：アンインデント
- ※インデントは半角空白２個
### Undo/Redo
- 編集 > もとに戻す Ctrl + Z：編集操作を取り消す
- 編集 > 繰り返し Ctrl + Y：元に戻した編集操作を再実行
### プレビュー内編集
- プレビュー内でも文字挿入・削除などの単純な編集が可能
## 3. ファイルの保存と終了
- ファイル > 保存 Ctrl + S：現文書を保存
- ファイル > 名前を付けて保存 Ctrl + Shift + S：現文書を別名保存
- ファイル > 閉じる Ctrl + W：現文書を閉じる
- ファイル > 終了：viMarkdown を終了

# 【第2部：viMarkdown の便利な機能】
## 4. 日記・ノート管理：カレンダーから瞬時に記録
- 表示 > カレンダーバー：カレンダーバー表示・非表示切替
- 日付部分をクリック：その日付の ToDo/Note 文書を表示・作成
- 日記ファイルは デフォルトディレクトリ/diary 以下の 年/月/ ディレクトリに作成される
- diary/template.md を編集することでテンプレートを変更可能
## 5. データ編集：Markdown内でCSVテーブルを自在に操る
- 「\`\`\`CSV」「\`\`\`」でCSVデータを囲むことで、CSVデータを表形式で表示
- CSV なので、表計算ソフトとのデータ交換が可能
- テーブル内にカーソルがあるとき、編集 > コンバート > CSV → GFM表 で変換可能
## 6. ビジュアル表現：SVGの表示と編集
- 「\`\`\`SVG」「\`\`\`」でSVGソースを囲むことで、図形を表示可能
- Ctrl + Space でSVG構文補完ダイアログ表示
- SVGソースを生成AIに作らせ、viMarkdown上ですぐ確認・編集できます。
## 7. diffで文章を比較する
- ツール > diff：空文書と比較
- ツール > diff with file...：選択ファイルと比較
- diff表示状態：
  - 対応する行を左右に揃えて表示
  - ツール > diff：diff状態解除
  - ≪ ≫ ボタン押下により文章を相手文書に反映
  - 変更ブロック内の挿入単語を右ボタンクリック → 「相手文書に反映」により単語を相手文書に反映
## 8. コマンドチートシートへの案内
- その他 > チートシート > Markdown
- その他 > チートシート > vi
